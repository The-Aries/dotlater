# Privacy

DotLater has **no accounts, analytics, ads, external servers or outgoing network requests**.

| Data | Where it stays | Purpose |
| --- | --- | --- |
| Tab ID, URL and temporary mark state | Browser session storage | Remember which tabs are marked; cleared when the session ends |
| Auto-clear delay | Browser sync storage | Remember your setting; your browser provider may sync it across signed-in devices |

DotLater reads and changes favicon elements only when Edge permits page access. It does **not** read the page body, scan local file contents or collect your browsing history.

Removing the extension clears its extension data. Questions can be submitted through [GitHub Issues](https://github.com/The-Aries/dotlater/issues).
