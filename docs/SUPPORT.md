# Support DotLater

DotLater is free and MIT licensed. Sponsorship helps maintain the extension and support future browser compatibility.

## GitHub Sponsors

[Become a sponsor](https://github.com/sponsors/The-Aries) using either a one-time contribution or monthly support.

| Frequency | Amount (USD) | Tier |
| --- | ---: | --- |
| One-time | $1 | Thank You |
| One-time | $5 | High Five |
| One-time | $10 | Extra Thanks |
| Monthly | $2 | Supporter |
| Monthly | $5 | Sustainer |

All five tiers were published on November 1, 2026. They are **voluntary donations**; there are no exclusive features, guaranteed updates or priority support. GitHub charges the selected amount in US dollars.

## Contribute without paying

You can also [report a bug](https://github.com/The-Aries/dotlater/issues), review code, or submit a pull request with browser compatibility tests.
