Mark a tab.
Come back later.

A small dot to remind you which tabs to revisit.

How to use

  1. 1

    Pin DotLater. Find it in your browser's Extensions menu and choose Pin (or Show in toolbar).

  2. 2

    Mark a tab. Click the green dot. It turns yellow. Click again to undo.

  3. 3

    Come back. Switch away, then return. The yellow mark clears automatically after one second.

See it in action

Real browser test captures. Mouse clicks are not shown in this version.

Shortcut: Ctrl + Shift + X or ⌘ + Shift + X on Mac.

Settings: Open DotLater's extension options to change the auto-clear delay.
