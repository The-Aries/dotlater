DotLater
Install for Edge GitHub

Mark a tab. Come back later.

A small dot to remind you which tabs to revisit.

How to use

  1. 1

    Pin DotLater. Open the Extensions menu and choose Pin or Show in toolbar.

  2. 2

    Mark a tab. Click the green dot. It turns yellow. Click again to undo.

  3. 3

    Come back. Return to the tab to clear the mark automatically after one second.

Shortcut
Windows: Ctrl + Shift + X
Mac: ⌘ + Shift + X
